# User Preferences & Behavioral Constraints

1. **Tuyệt đối không tự ý push code lên GitHub (`git push`)**:
   - Chỉ thực hiện `git push` khi người dùng yêu cầu rõ ràng bằng lệnh hoặc xác nhận cụ thể.
   - Khi commit/merge cục bộ xong, phải dừng lại và hỏi/báo cáo người dùng trước nếu chưa có yêu cầu push trực tiếp.

2. **Tuyệt đối không tự ý mở và truy cập link web / browser**:
   - Không tự ý dùng browser subagent, mở trình duyệt hoặc truy cập các liên kết web bên ngoài nếu người dùng không yêu cầu cụ thể.
